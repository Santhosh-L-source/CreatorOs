## Summary
Fixes #1159 - Gantt bars now dynamically position and size based on actual task dates instead of hardcoded values.

## Problem
The Task Manager's Timeline/Gantt view was not visually representing the actual duration of tasks. Each task bar was rendered with hardcoded inline styles (`left: 10%; width: 40%;`) instead of values calculated from each task's Start Date and Due Date.

## Solution
Modified `public/js/task-manager.js` (lines 387-463) to implement dynamic positioning and sizing:

### Key Changes:
1. **Dynamic Position Calculation**:
   ```javascript
   leftPercent = ((taskStartDate - timelineStart) / totalDuration) * 100
   ```

2. **Dynamic Width Calculation**:
   ```javascript
   widthPercent = ((taskDueDate - taskStartDate) / totalDuration) * 100
   ```

3. **Timeline Range Detection**:
   - Automatically finds earliest start date and latest due date
   - Adds 5% padding on each side for better visualization

4. **Edge Case Handling**:
   - Tasks without dates use `createdAt` as start and +3 days as default duration
   - Tasks with `dueDate < startDate` get auto-corrected to 1-day minimum
   - Single-day tasks guaranteed 2% minimum width for visibility
   - All values clamped to 0-100% range

5. **Enhanced UX**:
   - Added timeline scale header showing date range (start, middle, end)
   - Improved tooltips showing "Start: Date | Due: Date" on hover
   - Maintained all existing styles and interactions
